# ExportDataApp

A C# application for exporting data.

## Features

- Data export functionality
- Built with C#

## Getting Started

### Prerequisites

- .NET Framework or .NET Core (depending on your version)
- Visual Studio or another C# IDE

### Installation

1. Clone the repository:
```bash
git clone https://github.com/liewvk/ExportDataApp.git
```

2. Open the project in Visual Studio

3. Build the solution

## Usage

Run the application and use it to export your data.
